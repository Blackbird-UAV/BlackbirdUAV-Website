# Security Policy

## Supported Versions

Current versions that is supported:

| Version | Supported          |
| ------- | ------------------ |
| 1.5.x   | :white_check_mark: |
| 1.4.x   | :x:                |
| 1.3.x   | :x: |
| < 1.3.x  | :x:                |

## Reporting a Vulnerability

To report a vulnerability, go to Security > Security Advisories to privately create a security advisory.
